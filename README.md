# BarberShop Booking System — DB Design

## О проекте
Логическая модель базы данных для системы онлайн-записи в барбершоп.
Описаны сущности, их атрибуты и связи, построена UML-диаграмма.

## Функциональность
* Регистрация клиентов
* Управление расписанием мастеров
* Бронирование услуг
* Уведомления клиентов

## Сущности
* Персоны
* Клиенты / Сотрудники
* Услуги
* Слоты обслуживания
* Роли и справочники

## Структура
src/        # описание сущностей  
docs/       # документация  
diagrams/   # UML диаграммы  

## Технологии и подходы
* Реляционные БД
* UML (Class Diagram)
* ER-моделирование

## Назначение
Учебный проект и база для разработки backend-системы.
