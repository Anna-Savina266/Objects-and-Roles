# Objects-and-Roles
Логическая модель базы данных для системы онлайн-записи в барбершоп. Определены основные сущности, их атрибуты и связи, построена UML-диаграмма. Модель поддерживает регистрацию пользователей, управление расписанием и бронирование услуг и может служить основой для backend-разработки
